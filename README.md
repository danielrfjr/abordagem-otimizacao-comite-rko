# UMA ABORDAGEM DE OTIMIZAÇÃO PARA O PROBLEMA DE COMITÊ DE AGRUPAMENTO

Comitê de agrupamento (clustering ensemble) utilizando o [RKO (Random-Key Optimizer)](https://github.com/RKO-solver).

## Estrutura

```
├── algoritmos_literatura/   # Algoritmos de agrupamento da literatura
├── comitedeagrupamento/     # Implementação do comitê de agrupamento
├── datasets/                # Conjuntos de dados
├── src/                     # Código-fonte
└── requirements.txt         # Dependências
```

## Instalação

```bash
git clone https://github.com/danielrfjr/abordagem-otimizacao-comite-rko.git
cd abordagem-otimizacao-comite-rko
pip install -r requirements.txt
```

## Resultados

A pasta `results/` não está no repositório por causa do tamanho. Os arquivos `all_results` e `partitions_for_R` estão disponíveis em [Releases](../../releases).
